# Инструкции локальному агенту

Репозиторий — один Tool. Не тащи сюда соседние Tools.

1. Прочитай `docs/DESIGN.md` целиком до правок.
2. Бери только открытые пункты из `docs/AGENT_TASKS.md` (один INVEST-срез за цикл).
3. Локально и без сторонних SaaS, если задача это позволяет. Сеть — только если пункт явно про сеть.
4. Не коммить секреты. `TOOL_TOKEN` только в `.env` / `compose.env`.
5. Проверка: `PYTHONPATH=src python -m pytest -q`.
6. Коммит на русском, по факту изменения. Не выдумывай статус «готово», если тест не гонялся.
7. Документы дизайна и задач обновляй в том же цикле, что и код.
